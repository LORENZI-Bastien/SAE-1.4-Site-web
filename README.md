# SAÉ 1.4 — Se présenter sur Internet

Projet de première année de BUT Réseaux et Télécommunications à Montbéliard.

## Objectif

Création d’un premier site personnel en HTML et CSS, avec présentation, centres d’intérêt et contacts.

## Travaux réalisés

Pages de présentation, navigation, mise en page et intégration de photographies.

## Outils et technologies

- HTML
- CSS
- Site personnel

## Organisation

Projet en autonomie.

## Présentation

[Mon portfolio](https://wonderful-chebakia-f83e9d.netlify.app/#projets)


## Consulter le site

Télécharger le dépôt et ouvrir `acceuil.html` dans un navigateur. Les pages HTML, feuilles CSS et images du site de première année sont présentes à la racine. La vidéo en anglais est exclue.
