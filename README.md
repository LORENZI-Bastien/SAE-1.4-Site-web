## Objectif

Créer un site de présentation personnelle de plusieurs pages, sans framework : présentation, centres d’intérêt, vidéo et contact.

## Pages du site

| Page | Fichier |
|---|---|
| Accueil | [`site/acceuil.html`](site/acceuil.html) |
| Qui suis-je | [`site/moi.html`](site/moi.html) |
| Centres d’intérêt | [`site/mes centres d'intérêts.html`](site/mes%20centres%20d'int%C3%A9r%C3%AAts.html) |
| Vidéo | [`site/vidéo.html`](site/vid%C3%A9o.html) |
| Contact | [`site/me contacter.html`](site/me%20contacter.html) |

Chaque page a sa propre feuille de style CSS dans le même dossier.

## Voir le site

Télécharger le dépôt (**Code** › **Download ZIP**), puis ouvrir `site/acceuil.html` dans un navigateur. La vidéo de la page Vidéo n’est pas incluse dans le dépôt.

Ce site de première année a depuis été remplacé par mon [portfolio actuel](https://bastien-lorenzi.netlify.app/).
